# Technical Documentation Lab

A practice repository for developing and validating a user guide
for GitHub Desktop and GitHub.

## Purpose

Demonstrate how technical writers can create, revise, review,
and maintain documentation using version control.

## Intended audience

Technical writers and reviewers who are new to Git and GitHub.

## Planned workflows

- Organize and edit documentation.
- Prepare changes on a separate branch.
- Review differences and commit changes.
- Share changes through pull requests.
- Incorporate feedback and merge revisions.
- Resolve conflicting edits and recover from mistakes.

## Validation environment

- GitHub Desktop 3.6.6 (x64)
- Windows
- GitHub Free personal account
- Private practice repository

## Project status

Documentation development and workflow testing are in progress.
This repository contains demonstration material, not client work.
